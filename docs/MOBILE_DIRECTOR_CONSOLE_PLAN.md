## 1. 导演台功能盘点 → 移动端可行性逐项判定

| PC 功能 | 实现原理 | 移动端可行性 | 判定 |
|---|---|---|---|
| 人偶放置（游标点放置、体型归一化） | glTF 导入 + 骨架收编 + scale 归一 | **高**。three.js GLTFLoader 原生支持骨骼模型；点选地面放人 = 射线拾取 + 单点触摸，天然比 PC 还顺手 | ✅ 首批 |
| 姿势/动作切换 | Action 槽位 + 库文件按需导入 | **高**。three.js AnimationMixer 播 GLB 内嵌动画；"扔文件即上架"的目录扫描改为 App 私有目录/文件选择器导入 | ✅ 首批 |
| 人物颜色染色 | 材质链插 Mix 节点 | **高**。直接改 `material.color` 或 onBeforeCompile 注入，移动端更容易 | ✅ 首批 |
| 移动到游标 | 根层级平移 | **高**。触屏拖动角色比 PC 更自然（长按拖拽） | ✅ 首批 |
| 机位相机（视口生成相机、进出相机视角） | 矩阵直算 | **高**。splat-viewer 已有 orbit 相机状态序列化（.svproj 同款），"机位"= 命名的相机状态槽 | ✅ 首批 |
| 显示/隐藏骨架 | 眼睛级显隐 | **中**。three.js 里 SkeletonHelper 开关，纯渲染层 | ✅ 首批（低成本） |
| 姿势库管理（类型分夹、按角色过滤） | characters.json + 目录扫描 | **中**。需要资产库 UI（角色列表/动作列表），配置 JSON 沿用导演台 schema 可直接复用 PC 端已整理的 characters.json | ✅ 首批简化版 |
| 场景持久化 | .blend 存盘 | **中**。复用 .svproj 思路扩展为"场景文件"（角色实例+机位+染色的 JSON） | ✅ 首批 |
| 录制输出（导演台的最终目的） | PC 端靠 Blender 渲染 | **待讨论**（见 §3） | ⚠️ 关键分歧点 |

**结论：导演台的功能本体（摆人偶、切动作、染色、机位）在移动端不仅可行，交互还可能优于 PC。**
真正的难点不在"能不能"，而在三件事：渲染管线差异、资产体积、录制输出（§2~§4）。

## 2. 核心技术差异与对策

### 2.1 渲染管线：Blender 场景 → three.js 场景
- 导演台角色是**网格+骨骼**模型（GLB），与泼溅模型（PLY 点云）是两种渲染对象。
- three.js 两者都能渲染，且**可同场景共存**：泼溅作背景/场景，角色站在其中——
  这反而是 PC 导演台没有的杀手级特性（人偶直接站在 3D 扫描实景里）。
- 风险：泼溅库的渲染循环是自管的（viewer.update/render），混入普通 mesh 需确认排序兼容
  （泼溅是排序绘制，GLB 是普通深度测试；预计 helpersScene 同款叠加方案可复用）。

### 2.2 动画系统
- GLB 内嵌动画 → AnimationMixer，即播即切，等价导演台"即点即切"。
- 动作库复用：导演台 pose-library 的 GLB 是 Blender 导出的标准 glTF，**无需转换直接可用**。
- 跨物种动作隔离规则（characters.json 的 animation_folders 语法）照搬纯逻辑层。

### 2.3 交互重设计（手机 ≠ 鼠标键盘，本项目的核心工作量）

**老板 22:40 补充的需求 + 我的方案：**

**① 平移观察视角（类 Blender shift+中键）— v0.3 按老板 22:53 反馈修订**

- **BUG 实锤**：真机上捏合缩放/双指拖动均无效（桌面 CDP 模拟双指通过，真机失效）。
  首要怀疑：canvas 未设 `touch-action: none`，浏览器把双指手势截去做页面缩放；
  次要怀疑：pointer capture 在部分安卓 WebView 上丢失第二指。**列为阶段 0 第一个修复验证项。**
- **老板交互方案（拍板采纳，22:58 二次确认）：**
  - **长按 1 秒进入移动模式**：默认手势 = 旋转，长按屏幕 1s 振动/视觉反馈后单指拖动 = 平移，
    松手自动回旋转模式（比显式模式切换更顺手，减少工具条依赖）
  - **方向盘控件**（工具条激活）：中央圆环**顺时针转 = 拉近/放大，逆时针 = 拉远/缩小**，
    圆环外上下左右四向按压 = 平移视口；**不含旋转**（老板拍板，旋转只靠单指拖）
  - **双指手势收敛**：只保留**捏合缩放**；双指拖平移取消（长按+方向盘已覆盖）；
    修复双指手势 bug 时仅验证捏合缩放真机生效
- 待确认：方向盘是否也需要「绕焦点旋转」方向（还是旋转只靠单指手势）

**② 可收放工具条**
- 底部悬浮工具球（可拖到屏幕任意边角防遮挡），点开弹出工具盘：
  `视角模式 │ 选择模式 │ 放置角色 │ 机位 │ 设置`
- 选择模式（点泼溅/模型查属性）与视角模式互斥，工具盘上高亮当前模式
- 收起时只留工具球，不挡画面

**③ 可收起属性面板**
- 选中对象（模型或角色）时从底部滑出属性面板，可整体下拉收起：
  - 位置 XYZ 数值输入 + 微调步进按钮
  - 缩放：均匀滑杆 + 数值
  - （角色）动作切换入口、染色入口
  - （机位）焦距/视角参数
- 数值输入用加减步进 + 直接键入双方式（触屏裸滑杆难微调）

**④ 3D 游标（老板 22:53 新增，对齐 Blender 游标概念）**
- 工具条设「放置游标」模式：激活后点屏幕任意处，射线求交把游标落到场景上
  （泼溅点云/模型表面/地面网格，按射线首个命中处）
- 游标 = 场景中一个可视标记（小十字/圆环，像 Blender）+ 全局唯一状态
- 用途：放置人偶一键落到游标（等价导演台「在游标点放置」）、移动到游标、
  机位焦点吸附到游标（分镜对焦利器）
- 精度：拾取泼溅点云可用渲染深度或最近 splat 中心；网格用射线三角求交；
  空白处落到当前视口地面平面（y=focal.y） 兜底

**既有交互提案（保留）：**

| PC 操作 | 手机交互提案（待讨论） |
|---|---|
| 3D 游标定点 | 点一下地面 = 放置/移动目标；长按 = 精确模式（放大镜） |
| 选中人偶 | 选择模式下单点拾取；选中环高亮 + 属性面板滑出 |
| 姿势菜单 | 全屏动作库面板（图标网格 + 收藏） |
| 机位管理 | 机位条：横向缩略图滑轨（每机位一张快照），点击切换；视口一键存机位 |
| 视角操作 | 旋转/平移模式显式切换（见上①），双指捏合缩放通用 |

### 2.4 资产与体积
- 21 只动物 + 若干人偶 GLB 总量估计数百 MB，**不能全打进 APK**。
- 方案：App 内置资产索引 + 首次使用时从 PC 局域网/网盘/文件选择器导入到 App 私有目录
  （复用项目存储层 store 适配）。characters.json schema 原样沿用。

## 4. 开发路线（讨论稿）

### 阶段 0：技术验证 spike（1 次发版内）
- [ ] **修复真机双指手势失效（仅捏合缩放）**：touch-action / pointer capture；双指拖平移按拍板移除，真机回归只验捏合缩放
- [ ] splat-viewer 场景中同时渲染 PLY + 骨骼 GLB，确认排序/性能
- [ ] AnimationMixer 播放导演台 pose-library 的真实 GLB，验证动作完整
- [ ] 中端机性能基线（角色数 × 泼溅点数 帧率曲线）

### 阶段 1：分镜编排 MVP（按拍板调整：相机分镜优先）
1. 交互基建：长按进移动模式 + 修复双指手势 + 方向盘控件 + 可收放工具条 + 属性面板（§2.3）
2. **3D 游标**：放置游标模式 + 游标渲染 + 人偶放置/机位焦点吸附游标
2. 角色库页（复用项目管理器双页框架 + 卡片列表 + 资产导入），几只人偶打样
3. 场景页：放置/点选/长按拖动/删除角色
4. 动作切换面板（Mixer 即点即切）+ 骨架显隐
5. 染色（色板九色，等价 v1.3）
6. **分镜相机系统**（本批核心）：视口一键存机位（含缩略图快照）→ 机位条滑轨切换/平滑过渡 → 机位参数可编辑（属性面板）
7. 场景文件持久化（扩展 .svproj schema → .svscene：角色实例 + 机位 + 染色）

### 阶段 2：编排增强
8. 多角色支持强化（编队移动、朝向控制）
9. 分镜序列（机位排序 + 转场时长 + 一键按序播放预览）
10. 录制输出（远期，按需重启：屏幕录制 → App 内录 → 回传 Blender 终渲）

### 阶段 3：生态联动
9. characters.json / pose-library 与 PC 端保持同 schema，PC 整理资产 → 手机直接用
10. （若选 C）场景文件回传 Blender 终渲

## 5. 风险清单

| 风险 | 等级 | 对策 |
|---|---|---|
| 泼溅+GLB 混渲排序冲突 | 中 | 阶段 0 spike 优先验证；fallback：分页切换渲染 |
| 中端机帧率（多角色×大泼溅） | 中 | 角色数上限、LOD/点数降采样 |
| 资产导入体验（数百 MB） | 中 | 局域网 HTTP 导入工具（PC 端一键推送到手机） |
| GLB 来自多源（FBX 转换/贴图重定向）兼容性 | 低 | 导演台已趟过的坑全部有记录（Mirror 应用、贴图 pack、动作名清洗） |
| 触屏误操作 | 低 | 选中态+撤销（操作栈）设计进 MVP |
